# Decision Records

Record only decisions that are likely to be surprising, fragile, or easy to regress.
Do not add a record for every routine change.

## File naming

Use `YYYY-MM-DD-<slug>.md`.

## Template

```md
# <Title>

- Date: YYYY-MM-DD
- Status: Accepted

## Context

What constraint, bug, or trade-off forced this decision?

## Decision

What are we standardizing on?

## Consequences

What becomes easier or harder? What should future edits avoid?
```
